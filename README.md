# Playtime Kit

[**Download Playtime Kit for Windows**](https://github.com/Cxrpss/Playtime-Kit/releases/latest/download/Playtime-Kit.zip)

1. Extract the complete ZIP into a folder.
2. Open **PlaytimeKit.exe**.
3. Choose **Play**. Press **F6** in game for private match settings.

For future releases, press **Update app** inside the launcher. It downloads the small kit update, verifies it and restarts. Your installed game and saved match settings stay in place. No GitHub account is required.

If you used the older PC-hosted updater, download this version once to switch to GitHub updates. You can keep using the same installed game.

The kit downloads the selected Project Playtime build through your own Steam account when needed. This repository does not distribute game files.
